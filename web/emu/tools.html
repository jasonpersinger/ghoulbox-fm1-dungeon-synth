Quick start

  1. Return to the web synth and press Switch on. Controls that affect the running instrument remain disabled until it has started.
  2. Open MIDI, saves, audio & display below the instrument.
  3. Choose only the tools you need. MIDI preferences and the synth’s ordinary browser save are remembered on this device.
Nothing in this box writes to a connected FM-1. These controls belong to the browser synth. Use the separate web editor for hardware backups and editing.

MIDI

Play notes

  1. Connect your MIDI controller before or after switching on the synth.
  2. Enable MIDI in and allow MIDI access when the browser asks.
  3. Play normally. Messages on all MIDI channels are passed to GHOULBOX.

Velocity affects incoming Note On messages only. Choose Keyboard velocity to preserve the controller’s dynamics, or a fixed value to make every external note equally strong. Fixed 100 matches the FM-1’s built-in keys.

Control the drawn panel

Enable Panel CC mapping, then assign the CCs below in your controller’s editor. These mapped messages operate the control currently shown on the GHOULBOX screen—just like touching the corresponding knob or button. Other CCs continue to reach GHOULBOX’s direct parameter map.

Knobs

CCControlSend

Buttons

CCControlSend

Absolute 0–127 is the usual choice for standard knobs. The first value establishes the knob position without jumping; later values turn it. Choose Relative 1 / 127 when an endless encoder sends 1 clockwise and 127 counter-clockwise. MASTER is always absolute.

Button combinations with MIDI notes: hold a mapped layer button—FX, GLO, SCL, EDIT, SEQ or REC—then play notes F3 through G5. Those notes act as the FM-1’s 27 physical keys until released, so combinations such as FX + B work from a MIDI keyboard. Notes outside that range continue to play normally.
Buttons need both edges. Configure each button to send a high value when pressed and 0 when released. A toggle-only controller can leave a panel button held.

Portable saves

The emulator already remembers its flash in this browser. A portable state file is different: it lets you keep a dated copy, move work to another browser or device, and maintain more than the four visible project slots.

Export state

  1. Switch on the synth.
  2. Press Export state.
  3. Keep the downloaded .json file somewhere backed up.

The file includes the live session plus saved projects, user sounds, settings and other emulator storage.

Import state

  1. Press Import state and select a GHOULBOX state file.
  2. Read the replacement warning and confirm.
  3. The page validates the file, installs it and restarts.

Malformed data, bad checksums and invalid live projects are rejected before replacement.

Undo an import

Immediately before an import, GHOULBOX keeps one recovery copy of the state it is replacing. Press Undo last import to restore that copy. A later import replaces the recovery copy, so export important work rather than treating Undo as a backup history.

Browser storage is not a backup. Clearing site data, using private browsing, changing browsers or losing the device can remove the automatic save. Export state files regularly.

Record a WAV

  1. Switch on the synth, prepare the sound or project, and press Record WAV.
  2. Perform with the drawn panel, computer keyboard or MIDI controller. The recorder captures the final stereo mix: instruments, effects, ambience and the metronome click.
  3. Press Stop & download. Your browser saves a timestamped, 24-bit stereo .wav file.

The timer advances as audio chunks are secured. The meter shows the highest level reached, in dBFS. If it turns red or the completion message reports clipping, lower MASTER or the track levels and record again.

Local and live: audio is encoded entirely in this browser and is never uploaded. Recording captures a performance in real time; it does not render a saved project automatically.
Ten-minute limit: recording stops and downloads automatically at ten minutes. A maximum-length file uses roughly 151 MiB at 44.1 kHz or 165 MiB at 48 kHz, plus temporary browser overhead. On a phone or low-memory device, make shorter takes. Do not close or reload the tab before stopping.

There is currently no pause, MP3 or FLAC export. Convert the WAV afterward if you need a compressed delivery copy; keep the WAV as the lossless master.

Focus Mode

Press Focus screen, or click the FM-1 screen itself, to hide the panel and place the 240 × 240 display against black. This is useful on a phone beside a MIDI keyboard, for projection, or when recording clean screen footage.

  • Click or tap the enlarged screen to return.
  • On a keyboard, press Esc to return.
  • Audio, playback and MIDI continue while the panel is hidden.
  • If a WAV recording is running, leave Focus Mode before pressing Stop.

Troubleshooting

Controls are disabled

Press Switch on first. Import/export is also disabled while recording or while another file operation is underway.

No MIDI response

Enable MIDI in, grant browser permission, and reconnect the controller. Web MIDI support varies; current Chrome or Edge is the safest choice.

A button stays held

Make the controller send 0 on release, then switch Panel CC mapping off and on to clear held panel controls.

No downloaded file

Check the browser’s download indicator and permission settings. On mobile, the file may appear in the system Files or Downloads app.

Import is refused

Use an unedited state file exported by this emulator. A hardware-editor backup is a different format and cannot be imported here.

The recording clipped

Reduce MASTER or individual track levels until the peak stays below 0 dBFS, then make another take.

Preferences, saves, recovery data and recorded audio stay on the device running the browser. Only the files you explicitly download leave browser storage.
