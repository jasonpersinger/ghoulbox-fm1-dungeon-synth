# GHOULBOX 2.4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** GHOULBOX 2.4 for the FM-1 (shared core). Make flash room, fix three deferred bugs, and add a sleep timer, sequencer MIDI out, FREEZE and a live SCENES page.

**Architecture:** Everything lands in the shared firmware core (`firmware/src`) and follows its conventions:
- `felucca.c` is a unity build.
- Settings bytes go in `favorites.factory[15][..]`, and menu items are append-only.
- Host tests live in `tests/` and run via `tests/run_tests.sh`.
- The web editor (`web/editor.html`) mirrors the firmware's lists.

The master fade is one mechanism in `fx.c`, shared by the sleep timer and the SCENES switch.

**Tech Stack:** C (JieLi AC791N, LLVM -Os/minsize via `tools/build.py`), host gcc tests, web JS (`web/test_web.mjs`, node).

**Spec:** Agreed in chat on 2026-10-23 (the owner: "Knock them out. You're in control."). The decisions are recorded below.

## Global Constraints

- The app-slot spare must stay **≥ 16384 B** (`tools/build.py SLOT_SPARE`, `FELUCCA_SPARE_MIN`). Never lower the floor. Measure after every task: the `./build.sh` line `ok image N B` gives spare = 581564 − N.
- **Stored numbers are append-only:** menu ids, settings bytes, `TL_*` places, page order seen by saved projects. Old projects and settings must load and sound the same.
- **Audio is bit-identical** when a new feature is off or idle. That means no golden changes except the CRYPT choke fix, which updates its golden deliberately.
- The **sleep timer** offers OFF / 30 / 60 / 90 min, fades for 2 min, and is in MENU > SYSTEM. It's stored in settings byte `[15][13]`, where 0 = OFF.
- **SEQ OUT** is OFF by default and lives in MENU > MIDI. It sends sequencer notes on each track's MIDI channel (`seq.c` track channel function, line ~63). It's stored in `ui_prefs2` bit 4 (`0x10 << 16` = `PREF_SEQ_OUT`).
- **FREEZE** sits on SEQ TOOLS key F4 (today `TL_GAP`). It works on the selected track: steps that played on the last pass are kept at CHANCE 100 and those that didn't are cleared. It's one undo, and it turns DREAM's EVOL off if on.
- **SCENES** is a HOME page after DREAM. The first 5 white keys (F3 G3 A3 B3 C4) pick DUNGEON / CRYPT / TAVERN / CHAPEL / BLANK. The music fades out over 1.5 s, the scene loads (`ui.c gb_scene_load`), then it fades in over 2 s, and the transport keeps its state.
- **The serial console is removed from the GHOULBOX build** (`FELUCCA_CDC 0`). MENU > SYSTEM > USB SERIAL is hidden, and its id 11 stays reserved.
- Commits are GPG-signed (automatic). Work on branch `ghoulbox-2.4`; push it and open a PR. **Don't merge.**

## Review Focus

1. **A scene switch while the audio ISR renders tracks mid-change.** It must never crash or click. Load only while the fade gain is 0, and switch engines the way the UI's live engine change does (`ui.c select_engine` path), not the power-on shortcut `t->engine = t->eng_req`. Test: `scene_test` switches scenes 20× during playback and renders without NaN, clipping spikes or a stuck voice.
2. **The sleep timer ends and drones are latched or keys held.** It must end in silence and come back on the next touch. Test: a timer of 1 min (test hook) with a latched drone; after the fade the output is 0; a button press restores the gain.
3. **A DAW echoing SEQ OUT back into the FM-1** (MIDI feedback). Off by default; the guide warns about it. Also make sure sequencer notes on MIDI OUT get their note-offs on STOP. Test: play → stop → every note-on has a note-off.
4. **FREEZE during a SONG (chain) or with LEN < 64.** Refuse with "STOP THE SONG FIRST" like DREAM; only steps 1..LEN are affected. Test in `freeze_test`.
5. **Old settings with byte `[15][13]` holding garbage** (another firmware). Values above 3 read as OFF. Test in the settings migration test.
